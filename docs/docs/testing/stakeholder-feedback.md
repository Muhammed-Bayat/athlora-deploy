# Sprint 2 Stakeholder Feedback

Stakeholder feedback complemented Athlora's automated unit, integration, and end-to-end testing during Sprint 2. The client/stakeholder tested the deployed application and completed a structured Google Form, providing independent evidence about usability, key workflows, and improvements to prioritise in the bug tracker and backlog.

This activity did not replace automated testing. It tested the product from the stakeholder's perspective, including paths and presentation concerns that automated checks alone cannot fully assess.
