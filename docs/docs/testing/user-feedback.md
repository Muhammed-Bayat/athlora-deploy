# Sprint 2 User Feedback

User feedback complemented Athlora's automated unit, integration, and end-to-end testing during Sprint 2. The team distributed a structured Google Form to users who tested the deployed application, gathering independent feedback about usability, clarity of workflows, and defects or improvements to prioritise in the bug tracker and backlog.

This activity did not replace automated testing. It provided evidence from users interacting with the application without the implementation context held by the development team, helping identify friction in the product experience alongside automated quality checks.
